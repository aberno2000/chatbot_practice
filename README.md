#  Телеграм бот для квизов

Многофункциональный телеграм бот для создания и проведения интерактивных квизов с отслеживанием статистики пользователей.

##  Команды

| Команда | Описание |
|---------|----------|
| `/start` | Запустить бота и показать главное меню |
| `/quiz` | Начать новый квиз |
| `/stats` | Посмотреть общую статистику |
| `/answers` | Посмотреть ответы на последний квиз |

##  Кнопки клавиатуры

- **Начать игру** - Начать новый квиз
- **Статистика** - Посмотреть статистику
- **Мои ответы** - Посмотреть ответы на последний квиз

##  Структура базы данных

### Таблица `quiz_state`
Хранит текущее состояние квиза для каждого пользователя
- `user_id` - ID пользователя (первичный ключ)
- `question_index` - Индекс текущего вопроса

### Таблица `quiz_attempts`
Хранит информацию о каждой попытке прохождения квиза
- `attempt_id` - ID попытки (автоинкремент)
- `user_id` - ID пользователя
- `attempt_date` - Дата и время прохождения
- `total_questions` - Общее количество вопросов
- `correct_answers` - Количество правильных ответов
- `score_percentage` - Процент правильных ответов

### Таблица `user_answers`
Хранит детальные ответы пользователя
- `id` - ID записи (автоинкремент)
- `user_id` - ID пользователя
- `attempt_id` - ID попытки
- `question` - Текст вопроса
- `selected_answer` - Выбранный ответ
- `correct_answer` - Правильный ответ
- `is_correct` - Правильность ответа (True/False)

### Таблица `user_stats`
Хранит общую статистику пользователя
- `user_id` - ID пользователя (первичный ключ)
- `total_quizzes` - Всего пройдено квизов
- `total_questions_answered` - Всего дано ответов
- `total_correct_answers` - Всего правильных ответов
- `best_score` - Лучший результат в процентах
- `last_quiz_date` - Дата последнего квиза
